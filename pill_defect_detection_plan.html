01문제 정의와 접근 전략

1.1 문제의 본질

제약 QC 관점에서 "불량"은 다음과 같이 세분화된다. 이들은 대부분 국소적·미세한 텍스처/형태 이상이며, 위치가 정해져 있지 않다.

외관 결함

깨짐(crack)·찍힘(chip)·긁힘(scratch)·오염/반점(spot)·변색(discoloration)·이물질

형태 결함

결손(missing part)·변형(deformation)·크기 이상·쌍둥이(double)

인쇄/각인 결함

각인 누락·흐림·번짐·위치 오류
핵심 제약: 학습 데이터에 불량 샘플이 0장이다. 따라서 "결함의 모양"을 직접 학습할 수 없다. 모델은 "정상이 무엇인지"만 배우고, 그로부터 벗어나는 것을 불량으로 판정해야 한다. 이는 산업 결함 탐지의 표준 세팅(MVTec-AD 류)과 동일하다.

1.2 왜 지도학습 탐지 모델만으로는 안 되는가

RF-DETR·YOLOv12·RTMDet는 (bbox, class) 라벨이 필요한 지도학습 객체탐지기다. 불량 라벨이 없으면 손실(loss)을 계산할 수 없다. 두 가지 우회로가 존재한다.

  • 합성 결함 주입(Synthetic Anomaly): 정상 알약 위에 인공 결함(긁힘·반점·깨짐 마스크)을 합성해 불량 라벨을 생성 → 지도학습 탐지기 학습 가능. (DRAEM, CutPaste, NSA, Perlin-noise 기법)
  • 오픈보캐뷸러리 제로샷: GroundingDINO/YOLO-World에 "broken pill", "cracked tablet", "spot on pill" 같은 텍스트 프롬프트 → 학습 없이 즉시 추론. 정확도는 낮으나 초기 라벨링 부트스트랩에 유용.

1.3 권장: 3-트랙 병행 설계

TRACK 1 · 메인
합성결함 + 지도학습 탐지
정상에 인공결함 주입 → RTMDet/YOLOv12/RF-DETR 학습. 위치+박스 출력.
TRACK 2 · 베이스라인
순수 이상탐지
PatchCore/EfficientAD. 정상만으로 학습, 픽셀 단위 anomaly map. 데이터 제약에 가장 정합.
TRACK 3 · 제로샷
오픈보캐뷸러리
GroundingDINO/YOLO-World. 학습 없이 베이스라인 + 자동 라벨링 보조.
최종 운영 권장 구조 — 2-Stage 파이프라인
① Stage-1 (알약 검출/정렬): 정상 데이터의 bbox로 학습한 경량 탐지기가 영상에서 알약 ROI를 잘라내고 정렬(crop & align). → ② Stage-2 (불량 판정): 정렬된 ROI에 대해 이상탐지(Track 2) + 합성결함 탐지(Track 1)를 앙상블로 적용.
Stage-1은 "모든 영상에 알약이 있다"는 정상 데이터만으로 충분히 학습되며, Stage-2가 실제 불량 판정을 담당한다.

02데이터 설계 및 파이프라인

2.1 데이터 분할 (Split)

세트구성용도비고
Train정상 ~34,000장 + 합성결함Track1 지도학습 / Track2 정상 모델링합성결함은 train 한정
Validation정상 ~3,000장 + 실제 불량 일부임계값(threshold)·하이퍼파라미터 튜닝실제 불량 필수
Test정상 ~3,000장 + 실제 불량(held-out)최종 성능 보고학습/튜닝에 절대 미사용
가장 중요한 선결 과제 — 실제 불량 평가 셋 제작
불량이 0장이면 "모델이 잘 되는지"를 측정할 방법이 없다(합성결함으로만 평가하면 합성 분포에 과적합된 낙관적 수치만 나온다). 따라서 실제 알약을 물리적으로 손상(긁기·깨기·반점 찍기·일부 절단)시켜 촬영하거나, 생산 라인의 폐기 알약을 수집해 유형별 최소 30~50장, 총 수백 장의 실제 불량 셋을 만들어 val/test에만 사용한다. 이것이 프로젝트 성패를 가르는 핵심이다.

2.2 합성 결함 생성 (Track 1·2 핵심)

기법모사 결함방법 요약
Perlin-noise mask (DRAEM)오염·변색·얼룩펄린 노이즈로 불규칙 마스크 생성 후 외부 텍스처 블렌딩
CutPaste / NSA찍힘·이물질·국소 손상패치를 잘라 같은/다른 알약 위에 자연스럽게 합성(Poisson blending)
Scratch/Crack 합성긁힘·깨짐곡선 스플라인·밝기 그라디언트로 균열선 렌더링
형태 변형결손·변형마스크 일부 erase / elastic 변형으로 형태 이상 생성

합성 결함에는 자동으로 정확한 bbox/segmentation 마스크가 따라오므로, 별도 수작업 라벨링 없이 대량의 지도학습 라벨을 확보할 수 있다.

2.3 전처리 & 증강

  • 해상도: 미세 결함 보존을 위해 ROI crop 후 640px 기본, 정밀 실험은 800~1024px. (해상도↑ = 미세결함 검출↑ but VRAM·시간↑)
  • 정규화: 200종 간 색·크기 편차가 크므로 종별(per-type) 통계 또는 조명 보정 권장.
  • 증강: 회전·플립·약한 색 지터·조명 변화. 단, 결함처럼 보이는 강한 노이즈/cutout 증강은 정상 모델링을 오염시키므로 Track2에서는 자제.

05실험 설계 및 평가 지표

5.1 평가 지표

QC의 목표는 "불량을 놓치지 않는 것(높은 Recall)"이 우선이다. 단순 mAP보다 이상탐지 표준 지표를 함께 본다.

지표의미우선순위
Image-level AUROC불량/정상 이미지 분류 성능(임계값 무관)핵심
Pixel-level AUROC / PRO결함 위치 localize 정확도핵심
Recall @ 고정 FPR오검 허용치 내 불량 검출율 (예: FPR 1%에서 Recall)최우선(QC)
Precision / F1운영 임계값에서의 균형보조
mAP@50 / @50:95탐지 모델(Track1) bbox 품질Track1 한정

운영점은 "불량 거의 100% 검출 + 허용 가능한 오검율"로 잡고, val 셋에서 임계값을 결정해 test에 고정 적용한다.

5.3 검증 원칙

  • 실제 불량로만 최종 평가: 합성결함은 학습용. 점수는 반드시 사람이 검수한 실제 불량 test 셋으로 보고.
  • 약종 누수 방지: 동일 약종이 train과 test에 섞이지 않도록 일반화 실험은 약종 단위로 분리.
  • 재현성: seed 고정, config·체크포인트·메트릭을 Weights&Biases 또는 MLflow로 추적.
  • 통계적 안정성: 불량 셋이 작으므로 3-seed 평균 ± 표준편차 보고.
